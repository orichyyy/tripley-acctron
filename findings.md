# Target 55 Findings

- BSP v2.43 defines AEX as Account anomaly reporting, so the existing AEX simulator exchange is only
  transport evidence and cannot represent session heartbeat.
- OEX reports ATM status; reason B001 means ATM starts service and is the correct establishment
  vertical slice.
- SNS is a host-to-ATM line-test command. No RCV-ATM-SNS message is defined, so no SNS response is
  generated by default.
- ATM-to-host common messages are 720 bytes with the transaction code at byte offset 2.
- Host-to-ATM messages are 748 bytes with the transaction code at byte offset 0.
- OEX request body is 600 bytes and includes a 210-byte cassette area plus five secondary device
  statuses.
- OEX reply body begins with a four-byte rejection reason and 696 bytes of filler.
