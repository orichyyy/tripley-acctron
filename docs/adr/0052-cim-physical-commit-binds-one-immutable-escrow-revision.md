# CIM physical commit binds one immutable escrow revision

Customer confirmation, host posting, and Cash Acceptance Physical Commit Authorization bind the same immutable Cash Acceptance Snapshot revision and safe hash. Any later acceptance, return, rejection, device correction, or delayed count evidence advances the revision and invalidates prior authorization, preventing a physical commit from moving a different set or value of media than the customer and host approved while preserving currency-separated device facts for project policy.
