# Disconnect protection uses an irreversible activation boundary

Owner transport loss first enters a phase-specific suspect grace window during which only the same runtime identity may prove and rebind its existing lease. Grace expiry atomically activates Protection Authority, advances fencing, and permanently stales the old owner; an in-flight native command is allowed to establish its result or remain execution-unknown before any non-conflicting protective action, and customer-position media continues its configured take timeout rather than being immediately reclaimed.
