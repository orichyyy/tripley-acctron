# Hostd owns protection phase

Tripley Native Host is the sole authority for a CDM or CIM Protection Phase, deriving it from durably recorded authorized command dispatch, native outcomes, and relevant device observations. Application metadata may correlate an operation but cannot assert or mutate physical phase; a conflicting or insufficient observation after disconnect or host restart causes intervention rather than inferred progress or repeated physical action. This keeps protection valid when the application dies between native execution and application acknowledgement.
