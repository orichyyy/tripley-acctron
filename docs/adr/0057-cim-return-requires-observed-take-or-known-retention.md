# CIM return requires observed take or known retention

Returned or refused media remains non-terminal until a configured trusted source observes customer take or an at-most-once retract is confirmed into a known device area; rollback completion alone proves neither. Production CIM configuration must provide a verifiable take and/or safe retract path, unresolved customer-position media blocks escrow commit and new operations, and unavailable or conflicting observation escalates to Terminal Intervention rather than manufacturing custody certainty.
