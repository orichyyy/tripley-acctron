# CIM physical commit requires project policy authorization

CIM Physical Commit, customer confirmation, and host financial posting remain independent facts, and the framework does not impose one universal ordering between them. Each operation freezes a project-contributed Cash Acceptance Physical Commit Policy, and escrow may be committed only with a short-lived, one-use authorization proving its registered gates were satisfied; this permits bank-specific posting order without moving host business policy into the device adapter or allowing a custom flow to bypass safety prerequisites.
