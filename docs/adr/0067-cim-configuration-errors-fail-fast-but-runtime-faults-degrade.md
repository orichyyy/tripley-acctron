# CIM configuration errors fail fast but runtime faults degrade

An enabled CIM contribution cannot start with an invalid logical service, resource-group mapping, protection journal, command whitelist, finalizer plan, return policy, capability contract, or production/test boundary. Once a valid runtime is composed, temporary provider, device, recovery, protection, intervention, or cash-unit faults disable the affected deposit and shared cash-resource-group availability; only project readiness policy may elevate that degradation to whole-kiosk unavailability.
